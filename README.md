# Тихий берег

Офлайн-игра для Android. Юля расследует исчезновение 23 человек в посёлке на Волге. Кампания охватывает 12 глав и 300 уровней: 240 головоломок «Три в ряд» и 60 сцен поиска на каждом пятом уровне.

Отчёт о переработке, проверках и оставшейся художественной работе находится в [docs/REWORK_1_1.md](docs/REWORK_1_1.md). Требования к исходным изображениям описаны в [docs/GRAPHICS_ASSETS.md](docs/GRAPHICS_ASSETS.md).

## Запуск

Требуются Node.js 22.18 или новее и npm. Для локальной Android-сборки нужны JDK 17, Android SDK и Android-эмулятор или телефон с отладкой по USB.

```sh
npm ci
npm test
npm run typecheck
npm run android
```

Для разработки можно начать с `npm start` и открыть проект в совместимой версии Expo Go для SDK 54. Повседневная игра в установленном APK работает без сети.

## APK

В `eas.json` профиль `preview` собирает APK для установки на телефон, а профиль `production` — AAB. Для облачной сборки нужен аккаунт Expo и привязка проекта. При первом запуске EAS предложит создать или выбрать проект и настроить ключ подписи.

```sh
npx eas-cli login
npx eas-cli init
npx eas-cli build --platform android --profile preview
```

Локально можно собрать установочный APK с встроенными сценами, звуком и кодом:

```sh
npx expo prebuild --platform android
cd android
./gradlew :app:assembleRelease
```

Файл появится в `android/app/build/outputs/apk/release/app-release.apk`. Локальная конфигурация Expo подписывает его отладочным ключом. Для публикации используйте отдельный ключ через EAS.

## Устройство проекта

- `src/core/match3` отвечает за обмены, совпадения, специальные фишки, падение, препятствия и цели.
- `src/core/hiddenObject` хранит состояние поиска и определяет попадания в области предметов. Размер координатной плоскости сцены — 360×480.
- `src/core/story`, `src/core/progress` и `src/core/save` управляют главой, наградами и версионированным локальным сохранением.
- `src/data/levels` задаёт размеры поля, цели, препятствия и предметы поиска. Каждый пятый номер зарезервирован за поиском.
- `src/data/story` содержит реплики, развязку главы, описания улик и зависимости заданий.
- `src/assets` содержит оригинальные рисованные интерьеры, нарезанные позы Юли и локальный звук. PNG фишек и карта подключаются из `assets/game` через `gameArt.ts`.
- `src/screens` и `src/components` содержат экраны, навигацию, жесты и анимации.

Звезда выдаётся при первом прохождении уровня. Затем её можно потратить на следующее сюжетное действие. Пройденные уровни доступны для повторной игры через карту.

Для воспроизводимой переразметки уровней запустите `npm run campaign:generate`. Генератор сохраняет конфигурации и найденные прохождения. `npm test` воспроизводит каждое прохождение.
