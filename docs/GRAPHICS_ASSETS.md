# «Тихий берег» — графические ресурсы (AI concept art)

Файлы добавлены для использования в `Bereg_Game1`.

## Фишки и бонусы
`assets/game/tiles/` — десять отдельных PNG 256x256 с альфа-каналом:
`key`, `lantern`, `water`, `leaf`, `radio`, `crystal`, `rocket_horizontal`, `rocket_vertical`, `bomb`, `color_bomb`.
Шесть основных типов и четыре бонуса. Для React Native/Expo используйте статические `require`.

## Карта и героиня
- `assets/game/maps/village_level_map.webp` — иллюстрированная карта с дорогой уровней. Нарисованные кнопки на самой картинке **не являются нажимаемыми**; поверх необходимо создавать реальные кнопки и области касания, согласованные с координатами карты.
- `assets/game/maps/village_map_alternate.webp` — альтернативный художественный референс карты.
- `assets/game/characters/yulia_character_sheet.webp` — лист поз/эмоций Юли. Требуется последующая нарезка на отдельные спрайты с точной маской.
- `assets/game/characters/yulia_concept.webp` — концепт Юли, не игровой спрайт.

## Интерфейс
- `assets/game/ui/match3_ui_concept.webp` — визуальный **макет**, а не полноценный экран. Реальные интерактивные UI-компоненты должны быть написаны в React Native отдельно.
- `assets/game/ui/tile_sheet_concept.webp` — дополнительный визуальный референс для фишек и эффектов.

## Важно
Это изобразительные материалы, а не готовый игровой движок. Часть исходных изображений была создана генеративно, возможны неровные контуры и отблески. При интеграции используйте игровые PNG из `tiles`, проверьте качество на настоящем телефоне. Лист персонажа — референс: не показывайте все позы одним изображением.

Фото-референс реального человека **не включён** в репозиторий. Созданные стилизованные изображения героини включены для проекта.
